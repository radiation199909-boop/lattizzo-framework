## 1. 研究问题

**RQ1 命名先后** 一个服饰词，先出现在法令里，还是先出现在法令以外的记录里？两者相差多少年？意大利城市与明代有什么不同？

**RQ2 回应方式** 法令出手时，是针对一件具体的东西，还是界定一个身份能穿什么？这两类条款的比例在两边怎样随时间变化？

**RQ3 方法** 大模型辅助、人工复核的抽取，能否在拉丁文、意大利俗语和文言上建立可靠的带年代词表？错误集中在哪里？

## 3. 判定规则

样本小，并且是有目的选取，因此不做显著性检验。所有结果以 n/N 报告。主分析窗口 w 取25年，10年和50年两档作为敏感性分析。

**H1**

- 以佛罗伦萨为主，威尼斯单独报告。
- 在 M1 中可判定的概念里，法令以外在先的数目多于法令在先的数目，视为支持。
- 这一关系在三档窗口中至少两档成立，才写作稳定的支持。
- 威尼斯与佛罗伦萨方向不一致时，两者都如实报告，不合并。

**H2** 分两部分判定，两部分都成立才视为支持。

- H2a 洪武、永乐之后，即1425年及以后的明代中央法令中，每条涉及女性服饰的条款平均点名的新概念数，低于佛罗伦萨1400年及以后的同一指标。新概念指此前该立法单位法令中未出现过的概念。
- H2b 明代中央法令的 M3 高于佛罗伦萨的 M3。
- 挪用的描述是否常见，作为案例分析报告，不做统计判定。

**H3** 两部分都成立才视为支持。

- H3a 佛罗伦萨1500年及以后的身份条款比例，比1500年以前高出至少15个百分点。
- H3b 明代中央法令1368至1424年的身份条款比例不低于50%。
- 兼有类条款单独计数。敏感性分析中分别把兼有并入身份和并入物件，结论都成立才写作稳定。

## 5. 语料与范围

**立法单位** 佛罗伦萨，威尼斯，明代中央，明代地方。博洛尼亚只用于 K3 示范。

**时间** 1355至1600年。明代记述可延至1644年，单独标出。

**词类** 衣服名称，头饰与首饰，面料与工艺。颜色和纹样另作附表。泛称不进入 M1 和 M3。

**来源组**

- 法令。包括条文、会典、实录中的禁令和地方禁约。奏疏中的禁奢建议标为法令提议，不计入法令。
- 法令派生记录。包括盖印登记、查抄和起诉，不进入 M1 和 M3。
- 独立记录。包括清单、账簿、书信、方志、笔记、布道、文学和实物。

**年份**

- 佛罗伦萨历、威尼斯历一律换算为以1月1日为岁首的年份。
- 明代方志和笔记用刊刻或成书年份，所述时段另记。
- 明代中央法令用颁布年份，会典重申的年份另记。

**纳入与剔除**

- 主分析包括转述类法令和研究者转引的明代记述。
- 敏感性分析中分别剔除威尼斯、转述类法令、研究者转引的明代记述。
- 同一句话被多部方志转抄时，只保留最早的一部。

## 6. 测量

**记号** 立法单位 p，概念 c。L 为 c 在 p 的法令中最早出现的年份，N 为 c 在 p 的独立记录中最早出现的年份。窗口 w 取10、25、50年，主分析取25年。覆盖门槛 k 取3条记录。

**M1 分类**

| 情况 | 条件 | 归类 |
|---|---|---|
| N 早于 L | p 在 N 之前至少有一部已入语料的服饰法令 | 法令以外在先，间隔为 L 减 N |
| N 早于 L | 不满足上一条件 | 无法判定 |
| L 早于 N | p 的独立记录在 L 之前 w 年内至少有 k 条 | 法令在先，间隔为 N 减 L |
| L 早于 N | 不满足上一条件 | 无法判定 |
| L 等于 N | 无 | 同年 |
| 只有 N | p 在 N 之后至少有一部已入语料的服饰法令 | 法令未点名 |
| 只有 N | 不满足上一条件 | 无法判定 |
| 只有 L | p 的独立记录在 L 前后 w 年内至少有 k 条 | 仅见法令 |
| 只有 L | 不满足上一条件 | 无法判定 |

**子类型** 法令以外在先时，若 N 与 L 之间还有一部已入语料的服饰法令没有提到 c，记为滞后，否则记为首次回应。

**缺失法令标记** 按 laws_timeline.csv 记下 N 与 L 之间已知但未入语料的法令数。大于零时，间隔只作为上限报告。

**M3** 在 p 第一部法令之后首次出现于独立记录的概念中，法令未点名所占的比例。分母为法令以外在先、同年、法令在先、法令未点名四类之和。

**明代的预期说明** 明代中央法令集中在洪武至永乐，独立记录集中在嘉靖以后。明代的 M1 预计有较多无法判定，明代一侧的结论主要依靠 M2 和 M3。这一点在看到数据之前写明。

**M2 回应方式编码**

- 物件条款。条款以一件东西为中心，规定它的使用、数量、尺寸或价值，适用于全体或除少数豁免者以外的全体。
- 身份条款。条款以一个身份为中心，列出这个身份可用或不可用的东西，用来和别的身份相区别。标志是条文出现身份名称，并伴有许用、止许、不许僭用、以别于一类措辞，或者同一法令对不同身份给出不同标准。
- 兼有。两个中心同时存在，分不出主次。每次使用都在 decisions.md 写明理由。
- 判断顺序。先看适用对象是否为具体身份，不是则编为物件。是则看所规定的东西是否与别的身份不同，不同则编为身份。只是对这个身份禁止某物而无等级对照的，编为物件并记下适用对象。两种判断都说得通时编为兼有。
- 汇总单位为二十五年。

# 条款回应方式编码手册（M2）

本手册与作者编码、第二编码者编码所用的说明相同。每条法令记录编一个码，编码时不看任何模型输出。

## 三种编码

**物件（item）** 条款以一件东西为中心，规定它的使用、数量、尺寸或价值，适用于全体，或除少数豁免者以外的全体。

**身份（rank）** 条款以一个身份为中心，列出这个身份可用或不可用的东西，用来和别的身份相区别。标志是条文出现身份名称，并伴有许用、止许、不许僭用、以别于一类措辞，或者同一法令对不同身份给出不同标准。

**兼有（mixed）** 两个中心同时存在，分不出主次。尽量少用，用时在 notes 写明理由。

## 判断顺序

1. 条文的适用对象是一个具体身份吗？不是，编物件。
2. 是，条文给这个身份规定的东西是否与别的身份不同？是，编身份。
3. 否，只是对这个身份禁止某件东西，没有等级对照，编物件，并在 applies_to 记下适用对象。
4. 第2步和第3步都说得通时，编兼有。

“妇女”本身不算身份。只对妇女、只对男子的条款，按第1步看是否另有身份限定。

## 填写

- code 栏选物件、身份或兼有。
- applies_to 填条文点名的对象，如命妇、士庶妻、donna nobile maritata、meretrici，全体则填全体。
- notes 写拿不准的理由。
- 一条记录含多款时，按整条记录的主要中心编一个码。
- 明代中央法令的身份常写在节标题中，编码时连同节标题一起读。

## 示例

| 记录 | 条文大意 | 编码 |
|---|---|---|
| FI1356-007 | 任何妇女或少女不得穿用 sciamito 制作或饰以 guazeroni 的衣服 | 物件 |
| FI1562-02、05 | 贵族已婚妇女可戴至多三枚金戒指，首饰须用纯金；同一法令许乡间农妇用镀金银的扣件与两枚镀金银戒指 | 身份 |
| MING-C-64 | 天顺二年，官民衣服不得用蟒龙、飞鱼、斗牛、大鹏、像生狮子等纹样 | 物件 |
| MING-C-15 | 洪武三年，士庶妻首饰用银镀金，耳环用金珠，钏镯用银，服浅色团衫 | 身份 |

# Clause codebook (M2)

Translation of the instructions used by the author and by the second coder. One code per law record, assigned without seeing any model output.

## Codes

**item** The clause centres on an object. It sets its use, number, size or value, for everyone or for everyone but a few exempt persons.

**rank** The clause centres on a rank. It lists what that rank may or may not wear, to set it apart from other ranks. The signs are a named rank together with wording such as "is allowed", "only", "may not usurp", "to distinguish from", or one law giving different standards to different ranks.

**mixed** Both centres are present and neither is primary. Use it rarely and give the reason in notes.

## Decision order

1. Is the clause addressed to a specific rank? If not, code item.
2. If so, does it give this rank something different from other ranks? If yes, code rank.
3. If it only forbids this rank an object, with no contrast between ranks, code item and record the addressee in applies_to.
4. If both step 2 and step 3 fit, code mixed.

"Women" alone is not a rank. For clauses addressed only to women or only to men, apply step 1 to any further rank named.

## Filling in

- code is item, rank or mixed.
- applies_to is the group the clause names, such as 命妇 (titled wives), 士庶妻 (wives of scholars and commoners), donna nobile maritata, meretrici, or everyone.
- notes give the reason for any doubt.
- A record with several sub-clauses gets one code for its main centre.
- In Ming central laws the rank is often named in the section heading, so the heading is read with the clause.

## Examples

| Record | Clause in brief | Code |
|---|---|---|
| FI1356-007 (1356) | No woman or girl may wear clothes of sciamito or trimmed with guazeroni | item |
| FI1562-02, 05 (1562) | A married noblewoman may wear at most three gold rings, and her jewels must be pure gold. The same law allows country women gilded silver clasps and two gilded silver rings | rank |
| MING-C-64 (1458) | Officials and commoners may not wear python, flying-fish, bull, roc or lion patterns | item |
| MING-C-15 (1370) | Wives of scholars and commoners wear gilded silver ornaments, gold and pearl earrings, silver bracelets and a light-coloured robe | rank |

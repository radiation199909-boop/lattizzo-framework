# lattizzo-framework

论文 *An Animal Called Lattizzo. Naming New Dress in the Sumptuary Laws of Renaissance Italy and Ming China*（DH2027）的代码、规程与小型演示。

论文要问的是，一个服饰名称先出现在禁奢法里，还是先出现在法令以外的记录里，又有多少名称法令始终没有点到。我们用大模型抽取名称，逐条人工复核，把写法归并为带年代的概念，再比较法令内外的首见年份。本仓库包含完整的方法，并在19条真实记录上从头跑到尾。

## 仓库内容

| 目录 | 内容 |
|---|---|
| `src/` | 流程代码。抽取、复核表、概念、归并审查、测量、一致性、SKOS 导出 |
| `prompts/` | 论文所用的两份提示词原文，SHA-256 见英文说明 |
| `demo/` | 19条出自已刊校订本的真实记录、主模型的缓存输出、样例概念的复核归并表、条款编码与预期输出 |
| `docs/` | 方法、归并规则、数据结构、条款编码手册、标注说明，以及冻结的预先登记与英文摘要 |
| `sample/` | 正文讨论过的14个概念，CSV 与 SKOS 两种格式 |
| `results/` | 论文表格与附录中的汇总计数 |

完整语料、金标准、概念表和全部模型输出属于正在进行的博士课题，现阶段不公开。每个数字怎样得出，这里都能看到，演示在真实文本上走完每一步。

## 运行

```
pip install -r requirements.txt
bash run_demo.sh
```

不需要 API 密钥。演示读取 `demo/model_output.jsonl` 中主模型的缓存输出，结果写入 `out/`，可与 `demo/expected/` 对照。要自己调用模型，把密钥写进本地 `.env`，用法见 `src/extract.py`。

## 演示说明了什么

演示把第3步跑两遍，一遍不用复核归并表，一遍用。同样19条记录，同一个词得到不同的类别。lattizzo 不归并时拆成两个词，一个只见于萨凯蒂1395年的故事，一个只见于1472年的法令；归并后是先见于法令以外、法令滞后跟进。ghirlanda 的旧拼法 grillanda 单独看先见于法令以外，归并后发现1356年的法令已有此词。gamurra 归并后变成法令在先。

写法的取舍会让词在类别之间移动，所以归并要由人按事先写定的规则来做，这是论文在方法上的主要发现。演示的数字不是论文结果，19条记录太少，论文的计数见 `results/`。
